# ☕ Cafe Blend - Responsive Coffee Website

A modern, sleek, and fully responsive coffee shop website designed to provide a seamless user experience across all devices. This project features a clean, professional user interface built entirely from scratch with vanilla web technologies.

## ✨ Features
* 📱 **Fully Responsive Layout:** Optimized for mobile phones, tablets, and desktop displays.
* 🎨 **Clean UI Design:** Includes a sticky navigation bar, interactive menu grid, and testimonial sliders.
* ⚡ **Pure Native Web Tech:** Built using clean, semantic HTML5 and modern CSS3 without heavy frameworks.
* 🚲 **Smooth Interactions:** Dynamic mobile menus and interactive elements powered by vanilla JavaScript.

## 🛠️ Tech Stack
* **HTML5:** Semantic structural markup.
* **CSS3:** Flexbox, Grid layouts, custom animations, and media queries.
* **JavaScript (ES6+):** Interactive menus, scroll effects, and dynamic UI logic.
